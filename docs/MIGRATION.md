# 从旧 Annotation 补丁迁移

旧方案直接修改 DS Bot 的前端文件，新方案是单独的 DSH bundle。两者不能同时注入。

1. 保存工作并确认旧补丁的版本、文件校验和与回滚备份。
2. 使用 **annotation v3 维护包**的回滚命令移除旧 annotation。v3 的回滚会保留 Finder 补丁停用状态；不要使用历史 v1/v2 安装器回滚。
3. 如果 DS Bot 已更新或文件校验不匹配，停止迁移，先适配；不要强制覆盖新版前端。
4. 通过 DSH 插件管理器安装本独立包，然后完全退出并重启 DSH，使旧前端退出内存。
5. 在测试会话打开测试网页，检查右键只有两项、Quick 只插入一次、批量备注汇总、原有草稿不丢失、切换聊天不串写。
6. 在插件管理器停用本插件，验证菜单消失；再次启用后验证恢复。

CLI 续跑补丁涉及 Host 的另外两个文件，无需为此迁移撤掉。Finder 补丁继续保持停用。

本仓库不携带 DS Bot 整包、旧基线或用户安装路径。原本没有打过旧补丁的用户，直接安装即可。
